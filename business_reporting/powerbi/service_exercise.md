# Power BI service evidence exercise

Status: not executed. Requires an authorized Power BI account, suitable license and a completed Desktop report. Do not count this document as administration experience.

1. Publish only to a workspace you are authorized to use. Record workspace name, artifact name and publication time. Use no client or employer data.
2. Configure the dataset connection for the selected source. A local CSV needs an appropriately configured gateway for service refresh; a local desktop path alone is insufficient.
3. Assign only the access needed for the exercise. Test with an authorized viewer account if available; verify the viewer can read but cannot edit. Do not invite unrelated people.
4. Configure a refresh schedule consistent with the source update process. Capture the refresh history and duration, then compare totals with the source controls.
5. In an isolated practice copy, temporarily point the source at a nonexistent file to reproduce a failure. Capture the error, diagnose the source path, restore it and run a successful refresh. Do not modify a shared production report.
6. Document the root cause, correction, affected data and prevention step. Record what you personally performed and the exact results.
